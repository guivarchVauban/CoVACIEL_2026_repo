# Remarques
- Tu dis souvent "C'est très simple"
- Eviter les "C'est quoi ?" plutôt "Qu'est ce que c'est"
- Numéroter les diapos en 4/11 5/11
- Dans le sommaire numéroter les titres
- Tu as dis 190cm, plutôt 190mm pour la taille de la voiture
- C'est plutôt ROS 2 Jazzy qui impose ubuntu
- Ce n'est pas un bit de start mais un octet
- Il faut rajouter une partie "Plannification"
- Rajouter une partie Réseau (ROS Domain ID, Point d'accès wifi...)
